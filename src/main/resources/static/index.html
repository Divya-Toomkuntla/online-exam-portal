Waking the server
The free host sleeps when idle, so the first visit can take a minute.

From sign-up to score in three steps

  1. Register

    Create a student account. Passwords are stored as BCrypt hashes and logins use signed JWT tokens.

  2. Sit an exam

    Pick an exam and the timer starts. Each student gets a random set of questions, in random order, with shuffled options.

  3. Review your answers

    Submit, or let the time run out. You see your score and every question with the correct answer.

What the server takes care of

One attempt per exam
Enforced by a unique constraint in the database, not just the page.
The timer is checked twice
The browser counts down, and the server rejects answers that arrive after time is up.
Answers stay on the server
The correct answers are not sent to the browser until the exam is submitted.
Separate admin tools
Admins create exams, import many questions at once, and reset attempts. Students cannot reach these.
